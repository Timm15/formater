# Formater

Конвертер и компрессор файлов, который работает прямо в браузере: фото, видео, аудио, PDF, таблицы и документы. Файлы никуда не загружаются.

Сайт: https://timm15.github.io/formater/

Весь сайт — один файл `index.html`. Библиотеки конвертации подгружаются с cdn.jsdelivr.net по мере надобности.

Удаление фона работает на моделях U²-Net (u2netp и silueta, лицензия Apache 2.0, папка `models/`) и onnxruntime-web: всё считается в браузере.

Языки интерфейса: русский, английский, китайский. Тексты лежат в `i18n.js` (словарь «русская строка → [en, zh]» и правила для строк с числами). Язык выбирается автоматически по браузеру и переключается кнопками RU/EN/中文 вверху.

Модели удаления фона: `u2netp` («Быстро»), `silueta` («Точнее») и ISNet general-use («Максимум»), все Apache 2.0. Файл `models/isnet.onnx` хранит веса в fp16 (90 МБ) и при загрузке разворачивает их в fp32, отличие от оригинала не больше 0,001.

Метаданные (вкладка «Метаданные»): чтение и удаление лежат в `meta.js`. JPEG, PNG, WEBP, GIF, MP3, WAV, FLAC и MP4/MOV переписываются по блокам без пережатия, PDF чистится через pdf-lib, Word/Excel/PowerPoint через JSZip, WEBM/MKV/OGG пересобираются Mediabunny без тегов, HEIC сохраняется в JPG. EXIF читается библиотекой exifr. Страна по координатам определяется офлайн по карте границ world-atlas (Natural Earth 1:50m), координаты никуда не отправляются.
